# Lumio

## Sobre o Projeto

O **Lumio** é um projeto acadêmico desenvolvido com o objetivo de aplicar conceitos de desenvolvimento web, design de interfaces e experiência do usuário.

A proposta é dividida em duas partes:

### Site Institucional

Antes de acessar a plataforma, o usuário conhece a proposta da Lumio através de um site institucional desenvolvido para apresentar a solução, demonstrar seus diferenciais e explicar como o sistema funciona.

O objetivo dessa etapa é gerar interesse nos cursos oferecidos, destacando benefícios como:

- Trilhas de aprendizagem organizadas;
- Acompanhamento de progresso;
- Projetos práticos;
- Certificados;
- Interface moderna e intuitiva;
- Organização dos estudos em um único ambiente.

### Plataforma de Estudos

Após a apresentação da proposta, o usuário pode acessar a plataforma de estudos, onde encontra recursos voltados para o aprendizado em tecnologia.

Entre as funcionalidades desenvolvidas estão:

- Cadastro e login de usuários;
- Dashboard de acompanhamento;
- Trilhas de aprendizagem;
- Controle de progresso;
- Visualização de cursos;
- Projetos práticos;
- Interface responsiva.
